[01]

Richprinted is designed to feel exactly like print() until you need more. Pass it a list, a dict, or a primitive, and it figures out how to format it well. Need more control? Every formatter accepts a rich set of keyword arguments for filtering, sorting, truncating, styling output and many more (viz documentation).

To use richprinted, you simply import the library and call a singleton rprint() just like print() passing it appropriate kwargs or solely the value.

When designing the logic behind richprinted, my main focus was extensive customizability, hence the keyword arguments meant to enhance and fit every users needs.
